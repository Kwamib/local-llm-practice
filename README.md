# Local LLM practice set

Practice files for the [Local LLMs with Ollama](https://kwamib.dev/resources/local-llms) track on kwamib.dev.

Larkspur County is made up. Its ten towns, their web pages and everyone named on them are fictional, so the right answers never change and no real person is ever named by mistake.

## What's here

- `pages/`: one web page per town, saved as plain HTML. Each one tests a different trap: a former mayor, an acting mayor, a mayor-elect, a council table, a town with no mayor at all, and more.
- `answers.csv`: the right answer for each page, and what makes it tricky. `NONE` means the page doesn't name a mayor or acting mayor.

The lessons tell you which files to use and when. Nothing here needs the internet, and nothing here costs money.

## Using it

```bash
git clone https://github.com/Kwamib/local-llm-practice.git
cd local-llm-practice
```
